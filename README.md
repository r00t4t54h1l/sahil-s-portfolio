# Sahil portfolio

The Next.js site lives in `sahilportfolio-client`.

```bash
cd sahilportfolio-client
npm run dev
```

## Deploy on Vercel

1. Import this Git repo in Vercel.
2. Set **Root Directory** to `sahilportfolio-client`.
3. Framework: Next.js (auto-detected). Deploy.

`vercel.json` is in `sahilportfolio-client` and also at the repo root if you deploy from the root without changing the directory.
