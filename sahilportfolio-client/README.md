# Sahil — Portfolio

Next.js portfolio for Sahil, a 4th-year ECE student at NIT Srinagar (2023–2027) who builds SaaS products integrated with IoT. Layout follows the [Portfolio Design (Community)](https://www.figma.com/design/Mxhdi06TpddqgwqamF7Zdi/Portfolio-Design--Community-?node-id=0-1) Figma file.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit copy, email, and socials in `src/data/site.ts`.
